# Heavenly Wallpapers v1.3

A native Android prototype for a premium Christian 4K/live wallpaper app.

## This version adds
- More cinematic device-rendered scenes for all six wallpapers.
- Animated atmospheric particles and subtle scene motion.
- Actual Android `WallpaperService` integration.
- Live wallpaper selection persisted between sessions.
- Static wallpaper application.
- 4K-oriented local image export to `Pictures/Heavenly Wallpapers`.
- Search, favorites, onboarding, explore, downloads and settings shells.

## Important
The scenes in this prototype are procedurally rendered inside the app so the APK remains lightweight. They are not yet photorealistic AI-generated 4K video assets.

## Build
Open the `HeavenlyWallpapers` folder in Android Studio, allow Gradle to sync, connect an Android phone with developer mode/USB debugging enabled, and run the `app` configuration.

## Next production stage
